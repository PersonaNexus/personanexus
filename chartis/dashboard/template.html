Healthcare advisory value cases

Five problems, five working prototypes

Each prototype estimates the annual value of solving one problem. The ledger below puts all five on one illustrative client so they can be compared and totalled. Open a problem to see its model output, how sure the estimate is, and the assumptions behind it.

All data here is synthetic and every benchmark is an assumption you can check. These are demonstration estimates, not client results. Hard (P&L) value and soft (capacity) value are never added together.
